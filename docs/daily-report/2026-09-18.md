## 4. 気づき・要確認

1. **AI 根拠生成が 6 日連続で 0 回**
   `meta.scoring` は `withAi: true` ながら `aiCallCount: 0` / `costJpy: 0.0` /
   `fallbackCount: 4,160` が 09-12 以降ずっと続いており、dealReasons は全件ルールベースの
   機械文で出力されています。CI では `ANTHROPIC_API_KEY` secret を渡しているため、
   secret が空／失効しているか、cost ledger の月次ガードに掛かっている可能性があります。
   次回スクレイプ前に secret と `data/state` の ledger を確認したいところです。

2. **S ランク 17 件がすべて HOME'S の投資用マンション（博多区 14／中央区 3）**
   表面利回りの掲載率が HOME'S 91%（1,349/1,476）に対して SUUMO・ふれんず は 0% で、
   利回りが載らない物件は推計値（fallback）に倒れるため、構造的に HOME'S が上位を占めます。
   スコアの公平性という点では、SUUMO / ふれんず の利回り取得（詳細ページ or 推計精度の改善）が
   引き続き最大の改善余地です。

3. **N/A が 45 → 50 に増加**
   内訳は HOME'S の一棟売りアパート 23・一棟売りマンション 8・戸建賃貸 6・一棟売りビル 4 ほか。
   築年が取得できず N/A 判定（PRD §5.2.10）に落ちているものが中心で、一棟物件の築年パースが
   弱い可能性があります。件数は小さいものの、一棟系は単価が大きいので拾えると効果は大きめです。

4. **CI の Node 20 非推奨警告**
   `actions/checkout@v4` ほか 5 アクションが Node 20 ターゲットのまま強制的に Node 24 で
   実行されています。現時点で実害はありませんが、いずれ v5 系への更新が必要です。
